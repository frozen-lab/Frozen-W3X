# Frozen-W3X - 魔兽争霸3《生化狂潮》解析、复刻与修复工程

本项目基于经典魔兽争霸3非对称塔防对抗地图《生化狂潮》（`生化狂潮_迁移版V2.w3x`），进行底层数据逆向解包、崩溃排查、现代游戏引擎复刻与玩法现代化设计。

---

## 目录结构

```text
├── docs/                                # 设计方案与分析文档库
│   ├── 01_复刻方案与创新设计.md           # 架构选型、商业引擎复刻与4项创新玩法机制
│   ├── 02_操控缓存与预判设计.md           # 输入缓冲(Input Buffer)、零误差补刀与预判算法
│   └── 03_地图崩溃深度排查与修复方案.md   # JASS 4.5万行代码缺陷深度排查与修复指南
├── 生化狂潮_迁移版V2.w3x                  # 原始魔兽地图归档文件 (41.9 MB)
├── pyproject.toml                       # Python uv 工程配置
└── main.py                              # 地图处理与流水线脚本
```

## 核心文档导览

1. **[01_复刻方案与创新设计.md](docs/01_复刻方案与创新设计.md)**：
   - 核心机制提炼（人类建造封门/经济滚雪球 vs 僵尸击破异变/生化感染）。
   - 引擎选型对比（Godot 4 独立联机、Unity 6、Web/Three.js 微信免下载开黑）。
   - 创新创意：Roguelike 科技卡牌构筑、地形挖掘破坏、昼夜光照、潜伏感染者（狼人杀模式）及单人割草 PVE。

2. **[02_操控缓存与预判设计.md](docs/02_操控缓存与预判设计.md)**：
   - 解决原生引擎“卡手/吞键”的 **输入缓冲队列（Input Buffer 120~180ms）**。
   - 极限走砍（取消后摇 Animation Canceling）机制。
   - 弹道时间与 DPS 预估的不漏刀判定，以及基于一阶运动学的技能预判瞄准算法。

3. **[03_地图崩溃深度排查与修复方案.md](docs/03_地图崩溃深度排查与修复方案.md)**：
   - **定位到 3 处致命闪退 Bug**：`war3map.j` 第 8090、8297、8506 行，在 `ydul_i` 循环中错误调用了残留值为 13 的 `GetForLoopIndexA()`，导致请求 `Player(12)` 越界引发内存崩溃。
   - 平台私有原生接口 `DzSetUnitModel` 在纯净魔兽局域网中的缺失闪退问题。
   - 0.5s 全图装备扫描定时器导致的性能与句柄隐患。
